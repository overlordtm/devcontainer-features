# Oh My Zsh Plugins

Adds, removes, or replaces the `plugins=(...)` array in the remote user's `~/.zshrc`.

This Feature only edits an existing Oh My Zsh configuration. It does not install Oh My Zsh or zsh. Install them first, for example with the `common-utils` Feature and `"installOhMyZsh": true`, or point the Feature at a `.zshrc` that already contains a `plugins=` assignment.

## Example Usage

Add plugins while keeping the ones already configured:

```jsonc
{
    "features": {
        "ghcr.io/devcontainers/features/common-utils:2": {
            "installZsh": true,
            "installOhMyZsh": true
        },
        "ghcr.io/overlordtm/devcontainer-features/omz-plugins:0": {
            "add": "zsh-autosuggestions, zsh-syntax-highlighting"
        }
    }
}
```

Remove plugins:

```jsonc
{
    "features": {
        "ghcr.io/overlordtm/devcontainer-features/omz-plugins:0": {
            "remove": "docker, kubectl"
        }
    }
}
```

Replace the whole plugin list:

```jsonc
{
    "features": {
        "ghcr.io/overlordtm/devcontainer-features/omz-plugins:0": {
            "set": "git zsh-autosuggestions zsh-syntax-highlighting"
        }
    }
}
```

## What it does

- Reads the existing plugin entries from the `plugins=(...)` assignment in the remote user's `~/.zshrc`.
- Applies `add`, `remove`, or `set`, then writes a single canonical `plugins=(...)` line in place.
- Handles both one-line and multi-line `plugins=(...)` assignments and preserves the rest of the file.
- Creates `~/.zshrc` if it does not exist and `add` or `set` is used.
- Keeps the file owned by the remote user.

## Options

| Option | Description | Type | Default |
| --- | --- | --- | --- |
| `add` | Comma or space separated plugins to add. Existing plugins are kept, and duplicates are ignored. | string | `""` |
| `remove` | Comma or space separated plugins to remove. Removing a plugin that is not present is not an error. | string | `""` |
| `set` | Comma or space separated list that replaces the entire plugins array. Cannot be combined with `add` or `remove`. | string | `""` |

Plugin names may contain letters, numbers, `.`, `_`, `+`, `@`, and `-`.

## Notes

- `set` is exclusive. Setting both `set` and either `add` or `remove` makes the Feature installation fail with an error.
- Empty option values are ignored. To clear the list, remove all current plugins explicitly.
- When `add` and `remove` are used together, plugins are removed first and then added, so the same name in both options ends up in the final list.
- If `~/.zshrc` is a symlink, the Feature updates its target file.
- If the existing `plugins=` line contains an unsupported entry (for example a path or shell syntax), installation stops with an error instead of rewriting it. Fix the line manually and rebuild.
